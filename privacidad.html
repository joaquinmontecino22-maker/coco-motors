Política de privacidad

Última actualización: 28 de octubre de 2026.

Qué es esta aplicación

Coco Motors usa una aplicación interna para conectar sus propias cuentas de Google (Gmail, Google Sheets, Google Drive y Google Calendar) con sus herramientas de automatización, con el fin de gestionar sus sorteos. La aplicación no está destinada al público general.

Qué datos se usan

La aplicación accede únicamente a los datos de las cuentas de Google de Coco Motors que fueron autorizadas expresamente, y solo para leer, crear o actualizar correos, planillas, archivos y eventos necesarios para la operación de los sorteos.

Cómo se protegen

  • Los datos no se venden, alquilan ni comparten con terceros.
  • No se usan con fines publicitarios.
  • Solo se almacenan en los sistemas de Coco Motors el tiempo necesario para la operación.

Uso de datos de Google

El uso y la transferencia a otras aplicaciones de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

Contacto

Para consultas sobre esta política, comunicate con Coco Motors a través de sus canales oficiales.
